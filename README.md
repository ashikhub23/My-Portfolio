# Mohamed Ashik S — portfolio

A cinematic, scroll-driven portfolio: a WebGL hero, a timeline, a 3D project
gallery and a closing scene, followed by plain About / Skills / Experience /
Contact sections. It is a **static site** — plain HTML, CSS and ES modules, no
framework and no build step.

## Run locally

```bash
python3 tools/serve.py          # http://localhost:5173
```

Any static server works (`npx serve`, `python3 -m http.server`); `tools/serve.py`
just disables caching so edits show up immediately. Open the page over `http://`,
not `file://` (browsers block ES modules and `fetch` on `file://`).

Needs a browser with WebGL2. Without it the scenes fall back to static content
and the text sections still work.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. On vercel.com choose **Add New → Project** and import the repository.
3. Framework preset **Other**, leave *Build Command* and *Output Directory*
   empty (the site is served from the repository root), and deploy.

Or from a terminal: `npx vercel --prod` in this folder.

After the first deploy, set your real address in `index.html` — the
`canonical`, `og:url`, `og:image` and `twitter:image` tags (marked `TODO`).

## What to edit

| To change | Edit |
| --- | --- |
| Name, headline, nav, About, Skills, Experience, Education, Certifications, Contact | `index.html` |
| Project cards: title, summary, features, tech, live and repo links | `public/data/projects.json`, then `python3 tools/build_project_cards.py` |
| Timeline cards (six milestones) | `src/scene3/layout3.js`, artwork via `tools/build_year_art.py` |
| Hero wordmark | `TEXT` in `src/scene/type.js`, plus `python3 tools/build_finale_plate.py WORD` for the closing scene |
| Résumé | replace `public/resume/Mohamed_Ashik_CV.pdf` |
| Colours and type | variables at the top of `src/styles/app.css` |

### Project links

`live` is set only for the three projects that have a deployed demo. `repo` is
`null` everywhere: add a GitHub URL to a project in `projects.json` and a
"Source on GitHub" button appears in its panel automatically. Nothing is shown
for a `null` link.

## Rebuilding generated assets

The portrait, finale artwork, card sprites and timeline art are generated by
scripts in `tools/`, so they can be redone from source.

```bash
pip install opencv-python numpy scipy pillow          # all scripts
pip install rembg onnxruntime                         # only to re-cut the photo
# ffmpeg must be on the PATH (hero video)

python3 tools/build_portrait_assets.py   # hero clip, finale figure, About photo, OG card, favicon
python3 tools/build_finale_plate.py      # closing scene background with the name
python3 tools/build_project_cards.py     # 12 gallery card sprites
python3 tools/build_year_art.py          # 6 timeline card illustrations
```

To use a different photo, replace `assets_src/portrait.png`, delete
`assets_src/portrait_cutout.png`, and run `build_portrait_assets.py`. Use a
photo with the subject against a plain-ish background; check the hair edge
after cutting.
